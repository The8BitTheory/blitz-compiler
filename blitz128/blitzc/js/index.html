blitzc

Port of the Blitz! 128 compiler (Skyles, 1986) in JavaScript. Compiler build of 2026-11-24. Everything runs locally in the browser. Open this page through a local web server (e.g. npx serve js), because ES modules do not load from file://.

    Off (menu items 1–3 of the original): there is no COLLISION command and RESUME must be given a line number (COLLISION, plain RESUME and RESUME NEXT are rejected as ILLEGAL COMMAND). In return the compiler is about 15 % faster and the compiled program about 20 % shorter. On (menu items 4–6): COLLISION and every form of RESUME are compiled; to make this work each statement gets a 2-byte header that checks for pending collision events and holds the statement length, which is where the extra size comes from. Original: the untouched Skyles runtime of 1986, with its known defects (e.g. FAST/SLOW, truncated graphics runtime image). Fixed original (V261123): the original runtime byte for byte with all bug fixes (truncated graphics image, FAST/SLOW, **RI in graphics programs) and no speed-ups, same speed and size as the original. Improved (V261123, includes the fixes): same bytecode, faster variable and array access and NEXT (about 10–20 % shorter run time), about 1.4 KB longer; with fast math also a faster multiplication and SIN/COS/TAN/ATN/SQR/LOG/EXP/^ (results bit-identical to the ROM, about 25 % faster floating-point code, about 3.2 KB longer, 2 KB tables are built behind the program at start). The Improved runtime needs $FC00-$FEFF (common RAM): the program must end below $FC00, and the string space is 768 bytes smaller.
